# Scenario 009 Runner-Only Smoke Validation

## Purpose

This document records the runner-only live smoke validation for
`scenario_009_suspicious_archive_staging`.

The validation proves that the local runner can be streamed from
`kali-attacker` to `ubuntu-victim01` over SSH and create the expected
runner-controlled artifacts on the target host. It does not prove live
defender-side telemetry, auditd coverage, Wazuh coverage, SIEM pipeline
coverage, Velociraptor collection, or detection from the live run.

Core boundary:

```text
attacker-side observed effect != defender-side observed artifact
```

`ATTACK_EVENT_JSON` lines emitted during this smoke are attacker-side observed
effects only. They are not defender-side telemetry, detections, alerts, or
collection results.

```bash

  'SCENARIO_009_BASE_DIR=/tmp/ai_soc_lab_scenario_009_real_smoke bash -s' \
```
